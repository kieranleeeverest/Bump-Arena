## 3. 修掉的两个（测试本身写错，不是产品问题）

### 3.1 `test_two_player_turns`：连续撞塔那段忘了给球速度

```gdscript
game.reset_game()            # 球速被清零
game.balls[0].p = ...        # 只摆位置
game.step(0.04)              # v=0 → 球不动 → 撞不到塔
```
`reset_game()` 之后 `v` 是零，球原地不动，断言必然失败。补上
`game.balls[0].v = -main_tower.inward * 620.0` 后 PASS。

### 3.2 `test_mode_turns`：期望值早于当前伤害模型

原断言 `towers[4].hp == 97`，但当前公式是：

```
base = clamp(round(10 * speed / FULL_DAMAGE_SPEED), 1, 10)   # FULL_DAMAGE_SPEED = 600
damage = base * TOWER_DAMAGE_SCALE(2)                        # 铁球不额外翻倍
```

`speed=160` → base 3 → 伤害 6 → **HP 134**（同场景下 `test_two_player_turns` 打印的也是 134）。
已改成 134 并注明公式。

**顺带用满速单独验证了伤害链路**（不受这两个脚本影响）：

```
HIT 0..6  expect=120/100/80/60/40/20/0  actual 全部相同
DAMAGE_PROBE PASS finished=true
```

## 4. 4 项失败的性质（都不是回归）

### 4.1 `test_weaknet_shot`：断言的是"松手进 pending"（**已删除**）

失败信息：`WEAKNET_FAIL release enters pending`。

**这恰恰是今晚被删掉的行为**：以前松手后要等服务端确认，本地置 `shot_pending`、显示
"等待确认"；现在松手即本地预演，不再进入 pending。这条断言编码的是旧架构，按新设计
应当反过来断言"松手即 `predict_active`"。

**已删除**（`2026-11-26 04:02`）。它继承 `LanMatchHost` 并自带 250–350 ms 假 RTT 的模拟
弱网骨架，但整套断言都建立在"等服务端确认"的旧协议上。真弱网现在由
`prototype/tests/load_test_clients.gd`（真 socket、多客户端）覆盖；需要假 RTT 时按新流程重写。

### 4.2 `test_lan_aim_sync`：断言旧回放管线（**已删除**）

失败信息：`LAN_AIM_FAIL non-acting view renders motion`。它检查的是"非行动方靠轨迹回放
看到球在动"，而现在非行动方是**本地预演**，回放只在兜底时出现。

**已删除**（`2026-11-26 04:02`）。瞄准同步现在的验证方式是：两端 `PREDICT` 状态 +
`PREDICT_END drift=0`（见 5.1）。

## 5. 两项专项验证

### 5.1 预演与权威的终态一致性（今晚改物理后最该确认的）

两台实例同机对拍：宿主走 `request_shot` + `_physics_process`，客户端走 `_predict_begin` +
`_predict_step`，从同一份快照起跑。

```
PARITY seed_dev=0.000000 frames=900 end_dev=0.000000 guest_settled=true
```

**900 帧后偏差仍是 0.000000**，说明边界网格化没有破坏两端的物理一致性。

### 5.2 观战扇出（8 客户端，2 座 + 6 观战，30 秒）

```
LOAD_SUMMARY clients=8 seated=2 spectator=6 room_updates=40 recv_bytes=485495 per_client=60687
NET_RATE in_flight=8 bytes/s=13816 total=233667
NET_RATE in_flight=8 bytes/s=13832 total=369963
```

- 宿主出口稳定 **13.8 KB/s**（≈ 1.7 KB/s / 人）
- 8 个客户端 30 秒合计收 485 KB（含连接瞬间的 room/hello 突发）
- 扇出按连接数线性、单人不膨胀——与改造前的测量一致，未被今晚改动影响
