# 弹射原型 v0.1

已确认：任意空白位置开始反向拖动，距离决定力度，可随时改变方向。玩家按 1→2→3→4 出手，瞄准 15 秒；全部球停下后换人。

母球（头像球）必须先碰到其他球或玩家，才具备伤塔资格；仅撞墙再撞塔不扣血。已有伤塔资格的母球撞墙后仍保留资格。其他球类暂沿用此前规则。直接撞塔不扣血，撞塔本身不激活资格。无伤害归属，可以误伤己方塔。铁球本次出手可反复伤塔；火球撞塔消失，有资格时伤害双倍。所有球停下后清除资格。

原型暂定值（并非原版数据）：普通伤害10，火球20，塔血100；两队暂定1、2对3、4；超时跳过；火球无资格撞塔也消失。请试玩后确认这些边界行为。

当前版本是本机轮流操作的手感实验室，暂不含联机、角色技能、音效或原版地图。金色外圈表示已碰撞。参数滑块可以调整力度、减速和反弹。重置恢复球位和血量，保留当前手感参数。

建议检查：母球直接撞塔不伤；母球只擦墙再撞塔不伤；母球撞球后再撞塔扣10；母球撞球、撞墙后再撞塔仍扣10；铁球被推动后能伤两方塔；火球撞塔扣20并消失；所有球停下后资格清空、换下一人。

安卓和iOS导出尚未完成；当前工程使用Godot，可用同一工程后续分别打包。
